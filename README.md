# FVTRACKER

web application for tracking processes in a frui&veg production

- general management
- seeding plants
- harvesting
- products creation
- storing
- selling

* clone repo
* install packages npm i
* fill .env file according to example
* run dev server npm run dev
* seed database (nav icon -> seed all)
